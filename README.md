# DairyMind — интеллектуальная система управления ресурсами молочного производства

Учебный прототип по лабораторной работе №11. Выбранный продукт — пастеризованное молоко. Интерфейс разворачивается на Vercel как React/Vite-приложение; API реализован через Vercel Functions. Виртуальный цех представлен интерактивной настольной схемой, а не полноценной VR-сценой.

## Возможности
- мониторинг выпуска, электроэнергии, воды и загрузки оборудования;
- синтетические временные данные (5 000 последовательных наблюдений);
- прогноз на следующий интервал и сравнение базовой модели, линейной регрессии, Random Forest и LSTM (результаты вычисляются локальным Python-скриптом);
- обнаружение аномального расхода энергии;
- рекомендации по ресурсам и переключение исходного/рекомендуемого режима;
- сценарии: базовый, повышенный спрос, ограничение сырья, простой линии, избыточное потребление;
- интерактивная схема виртуального цеха с состояниями оборудования.

## Запуск локально
Требуется Node.js 18+.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

## Развёртывание на Vercel
1. Создайте GitHub-репозиторий и загрузите в него содержимое этой папки.
2. На https://vercel.com/new импортируйте репозиторий.
3. Framework Preset: **Vite**.
4. Build Command: `npm run build`.
5. Output Directory: `dist`.
6. Нажмите Deploy. Дополнительные переменные окружения не нужны.

API доступно по адресу `/api/forecast`. В режиме локального Vite интерфейс использует встроенный демонстрационный расчёт, если серверная функция недоступна.

## Подготовка и обучение моделей (Python)
Рекомендуется Python 3.10–3.12.

```bash
cd ml
python -m venv .venv
# Windows Git Bash:
source .venv/Scripts/activate
# macOS/Linux:
# source .venv/bin/activate
pip install -r requirements.txt
python generate_data.py
python train_models.py
```

Скрипт создаёт 5 000 синтетических наблюдений с фиксированным seed, делит данные хронологически 70/15/15, обучает persistence baseline, Linear Regression, Random Forest и LSTM (если установлен PyTorch), рассчитывает MAE/RMSE/R² и сохраняет `model_metrics.json` и график. Данные симуляционные и не являются измерениями реального предприятия.

## Структура
- `src/` — React-интерфейс;
- `api/forecast.js` — серверная функция Vercel;
- `ml/generate_data.py` — генератор синтетических данных;
- `ml/train_models.py` — обучение и оценка моделей;
- `ml/data/` — генерируемый CSV (после запуска скрипта).

## Ограничения
Это демонстрационный прототип поддержки принятия решений. Рекомендации не управляют реальным оборудованием. Аномалия указывает на необычное поведение, но не устанавливает причину неисправности. Для промышленного использования нужны реальные обезличенные данные, технологическая карта, проверка инженерами и отдельная защищённая инфраструктура.
